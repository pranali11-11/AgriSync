# AgriSync Machine Learning Module

This directory houses ML models, pipelines, and evaluation scripts for AgriSync.

## Modules & Scope
- **Crop Recommendation**: scikit-learn / XGBoost model leveraging soil parameters (NPK, pH), rainfall, temperature, and region.
- **Machinery Demand Forecasting & Grouping**: Clustering and optimization models for machinery pool matching among small farmers.

All agronomic input recommendations generated by ML models remain subject to validation against source rule databases (`source="SAMPLE - verify with ICAR / state agriculture dept"`).
